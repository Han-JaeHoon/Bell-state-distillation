# Figures for the repeated-dynamics section

Generated by `scripts/make_report_figures.py`, which recomputes every number
from the repository's implementations before drawing anything.  Nothing is read
off a stored plot.

```
python scripts/report_verify.py          # the checks alone
python scripts/make_report_figures.py    # checks, then figures + CSVs
python scripts/make_report_figures.py --q 0.05 --eps-main 0.2
```

Outputs: `results/report_figures/` (PNG at 300 dpi and vector PDF) and
`results/data/report_figures/` (one CSV per figure, plus `verification.json`
and `report_figures_summary.json`).

## Setup

```
rho_0(eps) = (1 - eps) |Phi+><Phi+| + eps I/4
p_0 = (1 - 3eps/4, eps/4, eps/4, eps/4)      Bell order (Phi+, Phi-, Psi+, Psi-)
main comparison: eps = 0.15, q = 0.02   ->   p_0 = (0.8875, 0.0375, 0.0375, 0.0375)
```

Noise: the two-qubit **replacement** depolarizing channel
`D_q(sigma) = (1-q) sigma + q [I_ij/4 (x) Tr_ij(sigma)]`, `s = 1 - q`, applied
after every CNOT on that CNOT's two qubits.

**Iteration rule.** Each round's exact output state is the next round's input.
The Bell-isotropic form is used for the **initial state only**; no round twirls
or re-projects onto Bell-isotropic or Werner form.

Backends:

| protocol | CNOTs | round map used |
|---|---|---|
| Type 3 | 16 | exact Bell-diagonal recurrence, `s^4 / s^6 / s^5(1+s)` |
| Type 4 | 14 | exact Bell-diagonal recurrence, `s^2 / s^4 / s^3(1+s)` |
| 4Q | 5 | exact Bell-diagonal recurrence + `P_succ = D_4Q/4` |
| Type 5 | 14 | **full two-qubit density matrix** — its noisy map does not preserve the Bell-diagonal subspace |

For Type 5 the four Bell populations are read out of the full state as
`p_i(n) = <B_i|rho_n|B_i>`; they are plotted, but they do **not** describe the
state, which is why `C_Bell` is plotted alongside them.

## Verification (run before any figure)

Three implementations are compared: the recurrence as written in the note
(`scripts/report_recurrence.py`, which imports nothing from the package), the
repository's verified exact maps, and a full density-matrix simulation of the
actual circuit.

| check | result |
|---|---|
| CNOT counts | 16 / 14 / 14 / 5 — as expected |
| `q` = parent repository's `eps2` | `2.2e-16` (2-qubit Kraus), `6.9e-18` (5-qubit channel) |
| note vs repository map, 400 random Bell-diagonal states, 5 values of `q` | Type 3 `0`, Type 4 `0`, 4Q `3.3e-16` |
| note vs repository `P_succ` | `0` |
| map vs full circuit simulation, 40 random states | `<= 5.6e-16`; `C_Bell` of the simulated output `<= 3.6e-31` |
| along the `eps = 0.15` trajectory: note vs map | `0` (Type 3/4), `3.3e-16` (4Q) |
| along the trajectory: map vs full simulation | `<= 5.6e-16` |
| `|sum_i p_i - 1|` | `<= 2.2e-16` (Type 3/4/4Q), `4.4e-16` (Type 5) |
| invariant plane residual | `<= 2.2e-16` |
| `F` in the invariant plane vs `p_Phi+` | `<= 1.1e-16` |

The last two rows matter for the note's formulas: `F = (1 + 2x + z)/4` holds on
the Type 3/4 plane `y = -x`, and `F = (1 + x + 2z)/4` on the 4Q plane `y = -z`.
The two are **not** interchangeable — swapping them is off by `>1e-3` on these
trajectories, which `tests/test_report_recurrence.py` checks explicitly.

`C_Bell` of the simulated output staying at round-off is what licenses using the
Bell-diagonal recurrence for Type 3/4/4Q: the Bell-diagonal output is a property
of those maps, demonstrated here, not a projection imposed on them.

## Figures

**`fig01_bell_population_dynamics`** — the four Bell populations against round,
`eps = 0.15`, `q = 0.02`, `n = 0..50`, one 2x2 block per protocol.  Each block
has a full-range panel (`0..1`) and a zoomed panel showing only `Phi-`, `Psi+`,
`Psi-`; the marked point at `n = 0` is where all three start at `0.0375`.
Colour and marker are fixed by Bell state and identical in every panel.

**`fig02_common_attractor_all`** / **`fig02_common_attractor_type4`** — `F_n`
for the six tested `eps` at `q = 0.02` (left) and `|F_n - F_star|` on a log axis
(right), for all three Bell-diagonal protocols and for Type 4 alone.  Caption
wording: *at q = 0.02, the six tested Bell-isotropic initial states converge
numerically to the same protocol-dependent attractor.*

**`fig03_type4_input_one_round_asymptotic`** — Type 4: `F_0(eps)`, `F_1(eps)`
and the long-depth limit `F_star` on a fine `eps` grid, with the six tested `eps`
marked.  Panel (b) resolves the two break-even points, which are different
questions and differ in the fifth decimal.

**`fig04_type5_metastability`** — Type 5 from the full-state map to `n = 5000`:
(a) `F_n` against `log10(n+1)`, (b) `C_Bell` for `n <= 50`, (c) `C_Bell` over the
whole run.

**`fig05_type5_raw_vs_calibrated`** — the raw learned circuit against the
compilation-calibrated one, `F_n` and `C_Bell`.

**`figS1_4q_success_probability`** — 4Q per-round postselection probability for
the six tested `eps`, full range and the transient.

## Wording to avoid

The figures and captions say "for the tested `eps` values at `q = 0.02`", never
"for every `eps`".  No threshold is defined anywhere in this set; `F_1 = F_0` and
`F_0 = F_star` are reported as two distinct break-even conditions, not as
thresholds.
