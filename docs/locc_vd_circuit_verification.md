# Ideal six-qubit distributed (LOCC) SWAP-test estimator — blind circuit verification

**Status: BLIND.** Everything below comes from density-matrix circuits built out
of gates. No analytic matrix-square expression, no Bell-diagonal recurrence and
no previously derived estimator formula was used, at any point, to produce or to
check these numbers. The two-qubit operator reconstructed from the six-qubit
correlators is called **`T_6Q(rho)`** throughout and is deliberately left
uninterpreted; the comparison against analytic theory is a separate later task.

Generated by `scripts/verify_locc_vd.py`; raw numbers in
`results/data/locc_vd/`.

---

## A. What was GIVEN as circuit specification

This section records the specification that was handed to the implementation.
Nothing here is a result.

### A.1 Setting

Two independently prepared identical bipartite two-qubit states,
`rho_(A1 B1)` and `rho_(A2 B2)`, give the four-qubit data input
`rho (x) rho`. Alice owns `A1, A2`; Bob owns `B1, B2`. Each party holds one
**local** ancilla, both initialised in `|+>`.

### A.2 Six-qubit ordering (fixed throughout)

```
[ a , b , A1 , B1 , A2 , B2 ]   ->   wire indices 0, 1, 2, 3, 4, 5
```

with wire 0 most significant in the Kronecker product. The data input occupies
wires `(A1, B1, A2, B2) = (2, 3, 4, 5)` as `rho (x) rho`, so the **first copy
sits on `(A1, B1)`**.

### A.3 Gates

| party | gate | wires |
|---|---|---|
| Alice | `Fredkin(a ; A1, A2)` | `(0 ; 2, 4)` |
| Bob | `Fredkin(b ; B1, B2)` | `(1 ; 3, 5)` |

No gate crosses the Alice/Bob cut. The two Fredkins act on disjoint wires, so
their order is immaterial; the simulator nevertheless fixes the order
**Alice then Bob**.

Gates are **ideal exact Fredkins**. There is no noise, no CNOT decomposition,
no postselection, no twirling, no Bell-diagonal projection and no
re-isotropisation anywhere in this task.

### A.4 Branch structure (given as a sanity check, not as a formula)

```
ab = 00  ->  I
ab = 01  ->  S_B
ab = 10  ->  S_A
ab = 11  ->  S_A S_B
```

with `S_A = SWAP(A1,A2)` and `S_B = SWAP(B1,B2)`.

### A.5 Five-qubit baseline

Ordering `[c, A1, B1, A2, B2]` -> indices `0..4`, ancilla `c` in `|+>`
controlling **both** local swaps: `Fredkin(c; A1,A2)` and `Fredkin(c; B1,B2)`,
i.e. the ordinary controlled full-copy SWAP. It is built from the same gate
primitives, **not** from any analytic reference.

### A.6 Estimators

```
C_XX(O) = < X_a X_b  (x) O_(A1B1) (x) I_(A2B2) >
C_YY(O) = < Y_a Y_b  (x) O_(A1B1) (x) I_(A2B2) >
Delta_6Q(O) := C_XX(O) - C_YY(O)

Delta_5Q(O) := < X_c (x) O_(A1B1) (x) I_(A2B2) >
```

`O` runs over all sixteen two-qubit Pauli products on `A1 B1`:
`II IX IY IZ XI XX XY XZ YI YX YY YZ ZI ZX ZY ZZ`.

| Alice's embedded Fredkin is unitary on 64 dims | `0.000e+00` |

| Alice's gate commutes with every Pauli on `(b, B1, B2)` | `0.000e+00` |

| the four control branches match the table in A.4 | `0.000e+00` |

only on `(a, A1, A2)` and Bob's only on `(b, B1, B2)`**.

### B.5 The subtraction does real work

`C_XX` and `C_YY` individually are **not** the 5Q estimator. Over the 1920
comparisons on general non-Bell-diagonal random states:

* `C_XX` alone differs from `Delta_5Q` by more than `1e-6` in **1080** of them;
* `C_YY` alone differs by more than `1e-6` in **1920** of them (i.e. all).

Representative random case — state `pure_21`, observable `O = XZ`:

```
C_XX      = -0.5035377374        |C_XX - Delta_5Q| = 0.460506
C_YY      = +0.4605062397        |C_YY - Delta_5Q| = 1.424550
Delta_6Q  = -0.9640439770
Delta_5Q  = -0.9640439770        |Delta_6Q - Delta_5Q| = 3.33e-16
```

Worst case overall — state `bell_Phi+`, observable `O = XX`:
`C_XX = +0.5`, `C_YY = -0.5`, `Delta_5Q = +1.0`; each correlator is off by
`0.5` and `1.5` respectively, while their difference is exact.

## C. What was VERIFIED by comparing independent circuit implementations

Two routes to the six-qubit unitary were implemented and they share no
construction helper:

* **Route A** — the explicit 8x8 Fredkin matrix
  (`|0><0| (x) I_4 + |1><1| (x) SWAP`) embedded onto non-adjacent wires by
  tensor-leg transposition, applied as a product of two 64x64 gates.
* **Route B** — the complete six-qubit controlled action written directly as the
  permutation it induces on computational-basis states: read the six bits
  `[a, b, A1, B1, A2, B2]`, exchange the `A1/A2` bits when `a = 1`, exchange the
  `B1/B2` bits when `b = 1`. Route B calls no Fredkin matrix, no embedding
  helper and no gate product.

| comparison | result |
|---|---|
| `max |U_A - U_B|` (matrix level) | `0.000e+00` |
| `max |rho_6Q(A) - rho_6Q(B)|` over all 151 inputs | `0.000e+00` |

The agreement is exact rather than merely within tolerance because both
constructions produce the same 0/1 permutation matrix.

The five-qubit baseline was cross-checked the same way (gate-product route
versus independent basis permutation): `max |U_5Q - U_5Q^perm| = 0.000e+00`.

## D. What has NOT YET been compared to analytic theory

Deliberately out of scope for this task, reserved for the next one:

* `T_6Q(rho)` has **not** been compared to any closed-form two-qubit operator.

* `Delta_6Q(II)` has **not** been compared to any purity expression.
* The normalised Bell fidelity has **not** been compared to any closed-form
  function of `epsilon`.
* No analytic LOCC-VD derivation was read or used.

What *is* established here is narrower and purely circuit-level: **the proposed
six-qubit distributed construction reproduces the ordinary five-qubit SWAP-test
estimator, observable by observable, to floating-point precision, on 151 input
states spanning pure, Bell-diagonal, random full-rank and rank-deficient
families.**

## Protocol-level statements

These follow from the circuit structure recorded in section A and the locality
measurements in B.1; they are stated explicitly because they are easy to
misread.

* This is an **observable-estimation protocol, not a physical output-state
  distillation protocol.** Nothing in the circuit produces an improved physical
  state; what is produced is an estimator of an expectation value.
* **No postselection is used.** The final six-qubit state has unit trace and
  every measurement record contributes.
* **No quantum communication occurs in the 6Q implementation.** Alice's quantum
  operations act only on `(a, A1, A2)`; Bob's act only on `(b, B1, B2)`; the
  locality checks in B.1 are exactly this statement, verified numerically.
* **Classical communication is needed only to combine local measurement
  records** — each party measures its own ancilla in `X` or `Y` and its own data
  qubits, and the correlators `C_XX`, `C_YY` are formed by classical
  post-processing of the two records.
* **Bell fidelity is operationally LOCC-measurable** here because
  `Phi+ = (II + XX - YY + ZZ)/4` is a combination of *products* of local Pauli
  observables, each of which Alice and Bob can measure separately.
* This does **not** mean an arbitrary entangled two-qubit observable is
  LOCC-measurable. The sixteen Pauli products used in section B are product
  observables and are locally measurable; a general entangled observable `O` is
  used here only as a mathematical probe of the estimator's linearity, not as a
  claim about what Alice and Bob can measure.

## Reproducing

```
python scripts/verify_locc_vd.py      # writes results/data/locc_vd/
python scripts/draw_locc_vd_circuit.py # writes results/figures/locc_vd/
python -m pytest tests/test_locc_vd.py -q
```

Deterministic: a single seeded generator (`seed = 20261007`) in a fixed order;
no randomness enters the circuits themselves.
